# ¡Hola! 👋 Soy Duberly

**Backend & Cloud Engineer** con más de 3 años de experiencia desarrollando aplicaciones y servicios escalables.

Mi especialidad es el desarrollo **backend con NestJS / TypeScript**, junto con el diseño, despliegue y operación de soluciones en la nube utilizando **Google Cloud Platform (GCP)**.

## 🚀 Backend & Cloud

- **NestJS**
- **PostgreSQL · Prisma · OpenSearch**
- **REST APIs · Microservices**
- **Arquitectura Hexagonal · Vertical Slicing**
- **Docker**
- **Google Cloud:** Cloud Run, Cloud SQL, Cloud Storage, Cloud Tasks, Cloud Run Jobs, Artifact Registry, IAM, Cloud Scheduler y VPC
- **AWS · DigitalOcean · Cloudflare**

## 🤖 Inteligencia Artificial

Experiencia integrando **funcionalidades de IA y agentes inteligentes** en productos de recruiting y selección, incluyendo:

- Agentes de IA para procesos de **reclutamiento y selección**
- Entrevistas asistidas por IA
- Evaluación y scoring de candidatos
- Procesamiento asíncrono de tareas relacionadas con IA
- Integración de servicios de IA con arquitecturas backend y cloud

## 🏗️ Arquitectura & Ingeniería

Me interesa construir sistemas **mantenibles, escalables y confiables**, aplicando principios de arquitectura limpia, separación de responsabilidades y diseño orientado a servicios.

También tengo experiencia trabajando con **SCRUM**, gestión de proyectos y documentación técnica para facilitar la colaboración y evolución de los sistemas.
